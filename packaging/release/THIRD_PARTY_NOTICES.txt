Third party software
====================

This program includes code and libraries from other projects. Their licenses apply to those parts.

- shadPS4 (GPL-2.0-or-later): video and shader translation layers. https://github.com/shadps4-emu/shadPS4
- Dear ImGui (MIT), stb_truetype (public domain), miniz (MIT), xbyak (BSD-3-Clause), magic_enum (MIT)
- SDL3 (zlib), FFmpeg (LGPL-2.1-or-later), Vulkan Memory Allocator (MIT)
- FidelityFX FSR (MIT)
- SMAA (MIT, Jorge Jimenez et al.): the VR mode's SMAA; its licence is in gpu/third_party/smaa. https://github.com/iryoku/smaa
- AMD FSR SDK 2.4 Vulkan DLLs (runtime/fsr: amd_fidelityfx_loader_vk.dll, amd_fidelityfx_upscaler_vk.dll), used for FSR 4.1 on Radeon graphics cards, unmodified; the licence is LICENSE-AMD-FidelityFX-SDK.md in that folder.
- FSR 4 model files (runtime/fsr4_shaders): built by the Q2RTX project from the MIT-licensed FSR 4 source in AMD's FidelityFX SDK; the notice is LICENSE-FSR4-v07.txt in that folder.
- NVIDIA DLSS library (nvngx_dlss.dll in the runtime folder), used for DLSS anti-aliasing and upscaling on GeForce RTX cards. They are distributed under the NVIDIA DLSS license in the licenses folder.
- DLSS bridge (driveclub_dlss.dll, MIT): license in the licenses folder, source in gpu/dlss_bridge.
- The remaining runtime DLLs next to the program come from the MSYS2 CLANG64 distribution; each keeps its own license.

Source for the GPL parts is available from the project repository this release was built from.
